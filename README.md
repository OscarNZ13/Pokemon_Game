# ⚡ Pokémon Game

Juego de escritorio inspirado en Pokémon: elegís tu equipo, peleás por turnos contra la computadora y consultás la Pokédex.

![Java](https://img.shields.io/badge/Java-ED8B00?style=flat-square&logo=openjdk&logoColor=white)
![Swing](https://img.shields.io/badge/Java_Swing-5382A1?style=flat-square)
![Maven](https://img.shields.io/badge/Maven-C71A36?style=flat-square&logo=apachemaven&logoColor=white)

## ✨ Funcionalidades

- Menú, ingreso de nombre y selección de Pokémon.
- **Batallas por turnos** contra un jugador CPU.
- **Pokédex** con la información de cada Pokémon.
- Pokémon de tipo fuego, agua y normal (Charizard, Blastoise, Gyarados, Snorlax y más).
- Estructuras de datos propias (listas enlazadas con nodos) y POO con herencia e interfaces.

## 🚀 Cómo correrlo

1. Requisitos: JDK y Maven (o NetBeans).
2. Abrí el proyecto en tu IDE (NetBeans, IntelliJ...) y ejecutá la clase principal `PokemonGame_Project`.
